# homebrew-tap

Homebrew tap for [forge](https://github.com/chainlinn/forge) — CI/CD scaffolding CLI.

## Install

```bash
brew tap chainlinn/tap
brew install forge-cli
```

## Available Formulae

| Formula | Description |
|----------|-------------|
| `forge-cli` | 一键创建 GitHub + Docker Hub 仓库，生成 CI/CD 流水线 |
